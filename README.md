# Overview
The Dream Charter is a program for taking notes while playing large level based exploration games. It is intended for games like [Yume Nikki](https://en.wikipedia.org/wiki/Yume_Nikki) but can be used for any similar games.

The Dream Charter provides a structured format for recording information that can be analyzed automatically. This allows it to perform tasks that would otherwise be tedious by hand, such as pathfinding, tracking objectives across multiple locations, and finding locations with specific attributes.

A typical use case for the Dream Charter is to create a location for each place in the game. You can then attach associated information, such as objects that can be obtained there and catalogs of areas that have yet to be explored. Once your notes are connected, the program can answer queries such as finding paths between locations.

**First time using the Dream Charter or need a refresher? To get started read [Getting Started](./Documentation/getting-started.md).**
